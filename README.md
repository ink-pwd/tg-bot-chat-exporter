# tg-exporter

Telegram-бот для выгрузки переписок подключённых Telegram-аккаунтов за день в JSON.

Каждый пользователь бота видит и выгружает только те аккаунты, которые подключил сам.

## Запуск

Нужны Docker и Docker Compose.

1. Скопируйте `.env.example` в `.env` и заполните:
   - `BOT_TOKEN` — токен от [@BotFather](https://t.me/BotFather);
   - `TELEGRAM_API_ID`, `TELEGRAM_API_HASH` — с https://my.telegram.org → API development tools;
   - `SESSION_ENCRYPTION_KEY` — ключ шифрования сессий:
     ```bash
     python -c "from cryptography.fernet import Fernet; print(Fernet.generate_key().decode())"
     ```
     **Храните ключ отдельно от базы.** Если его потерять, все аккаунты придётся подключать заново;
   - `MYSQL_*` — пароли для MySQL;
   - `ALLOWED_USER_IDS` — по желанию: id пользователей Telegram, которым доступен бот.
2. Запустите:
   ```bash
   docker compose up -d --build
   docker compose logs -f bot
   ```
   Миграции базы применяются автоматически при старте бота.

## Логи

Логи пишутся в консоль (`docker compose logs bot`) и в папку `./logs`, отдельный файл на каждый день: `2026-10-05.log`, `2026-10-06.log` и т.д. Дата и время в логах — по UTC. Файлы старше `LOG_RETENTION_DAYS` дней (по умолчанию 30) удаляются автоматически.

Тексты сообщений, коды, пароли и сессии в логи не попадают.

## Подключение аккаунта

В боте: «Подключить аккаунт» →
- **QR-код** — отсканируйте его в Telegram на телефоне: «Настройки → Устройства → Подключить устройство»;
- **по номеру телефона** — код вводится кнопками. Не отправляйте код сообщением: Telegram аннулирует код, который кто-то переслал в чат.

Если включена двухэтапная проверка, бот попросит пароль и сразу удалит сообщение с ним.

Сессии хранятся в MySQL в зашифрованном виде. Если отключить аккаунт в боте, сессия завершается и в Telegram.

## Выгрузка

В карточке аккаунта: «Сегодня», «Вчера» или «Другая дата» (`04.10`, `04.10.2026`, `2026-10-04`). Бот присылает JSON-файл со всеми чатами, в которых за этот день были сообщения. Границы суток считаются по часовому поясу пользователя: его выбирают в «⚙️ Настройки → Часовой пояс». Пока пояс не выбран, используется `DEFAULT_TIMEZONE` (по умолчанию `Europe/Kyiv`).

Выгрузки на сервере не хранятся: файл остаётся только в чате с ботом. В Redis кешируется ссылка на уже отправленный файл (`file_id`) и счётчики. Повторный запрос за прошедший день в течение 24 часов бот отвечает мгновенно, не обращаясь к Telegram. Для сегодняшнего дня кеш живёт 10 минут, а кнопка «Обновить» выгружает день заново.

Файлы больше 20 МБ отправляются сжатыми (`.json.gz`). Одновременно идёт не больше `EXPORT_CONCURRENCY` выгрузок (по умолчанию 3).

Если сессию завершили в Telegram («Устройства» на телефоне), аккаунт помечается ⚠️, и его нужно подключить заново.

## Отчёт по поддержке

К каждой выгрузке, ручной и автоматической, прикладывается HTML-отчёт: оба файла приходят одним альбомом. Отчёт открывается в браузере и работает офлайн.

- **Обращения** — содержательные сообщения клиентов. Новое обращение начинается после паузы больше 3 часов. Приветствия, «спасибо» и «ок» не считаются.
- **Время ответа** — медиана и среднее от вопроса клиента до первого ответа поддержки по существу. Приветствия и «секунду, уточню» ответом не считаются. Отдельно считаются вопросы, оставшиеся без ответа на конец дня.
- **Топ-3 запроса** — вопросы, сгруппированные по смыслу на русском и украинском, без LLM. В группе считаются разные клиенты, а не сообщения.
- Графики: сообщения по часам и распределение времени ответа. Остальные темы и самые долгие ожидания показаны в свёрнутых блоках.

Анализируются личные чаты и группы. Боты и каналы не анализируются.

Группировка держится на словаре понятий `src/infrastructure/nlp/resources/concepts.toml`, где синонимы на русском и украинском сводятся к одному понятию. Если два запроса об одном и том же попали в разные темы, обычно не хватает слова в этом словаре. Стоп-слова и вежливые фразы лежат рядом, в `stopwords.txt` и `fillers.txt`.

## Автовыгрузка

В карточке аккаунта: «⏰ Автовыгрузка», где можно выбрать время или выключить автовыгрузку. Каждый день в это время (по часовому поясу владельца) бот присылает выгрузку за прошедший день.

- Если бот был выключен в нужное время, после запуска он выгрузит пропущенный день. При долгом простое выгружается только последний день.
- При сбое Telegram бот делает до 3 попыток с паузой 5 минут, потом сообщает об ошибке. Этот день можно выгрузить вручную.
- Если сессия аккаунта завершена, автовыгрузка выключается, и владелец получает сообщение. Если пользователь заблокировал бота, выключаются все его автовыгрузки.
- При смене часового пояса бот спрашивает, менять ли время автовыгрузок. Если не менять, время остаётся тем же, но уже по новому поясу.
